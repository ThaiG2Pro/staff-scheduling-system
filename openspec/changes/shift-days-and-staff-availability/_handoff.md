## 1. Implementation Patterns

- **Bitmask Solver Isolation & MRV Staff Selection (ADR-002 + User-approved Option 1):** `SchedulerWorkingState` holds immutable `shiftDayMask` (7-bit active days per shift) and `unavailableMask` (7-bit unavailable days per staff). Stage 1 gates all 3 `(d, sIdx)` loops and `pickBestFitStaff` in O(1), prioritizing fewest configured available days (`countAvailableDays7(unavailableMask)`) before Best-Fit `slack` → Jain → `staff.id` to preserve flexible staff for scarce days (zero behavioral change on MVP 7-day schedules). Stage 2 seeds each iteration's mutable `dayMask[s]` from `unavailableMask[s]!` ORed with `dayOccupied`, so swap mutations never erase days off.
- **Shared 2D Coverable Grid (FM-05):** `buildCellCoverableGrid(shifts)` (`Uint8Array(7 * 16)`) in `src/domain/hardRules.ts` is shared by `derivedMetrics.ts` and `schedulerDiagnostics.ts`. Both guard residual shortage with `if (cellCoverable[idx] === 0 && reqBig > shBig)` to prevent negative `uncoverableBigInt`.
- **Unified Eligibility (ADR-003):** `isStaffEligible(staff)` (`maxWeeklyHours > 0 && getStaffUnavailableMask(staff) !== 0x7f`) drives `autoScheduler.ts`, `derivedMetrics.ts`, and `staffMetrics.ts` (`utilization = null` when ineligible, automatically excluding 7-day-off staff from Jain Fairness Index, `ScheduleHealthBar`, and Rebalance Lens).
- **Backward-Compatible Schema v1 (ADR-001):** `storageSchema.ts` omits default `daysOfWeek: [0..6]` and `unavailableDays: []` on write, rejects malformed day arrays or persisted assignments targeting inactive shift days as `CORRUPT_SCHEMA` (routing to `recovery_locked`), and preserves 100% MVP snapshot parity.
- **UI & State Safety (ADR-003, ADR-004):** Shared `src/ui/common/WeekdayToggleGroup.tsx` (`Mon`–`Sun`). `ManageShiftsModal` enforces min-1 active day and opens `ConfirmDialog` via `previewDisableShiftDays` before atomic cascade delete. `assignStaffToShift` and `restoreAssignmentsSnapshot` (`Ctrl+Z` Undo) both filter/reject inactive shift days.

## 4. Where QA Should Focus

1. **FM-03 Pin Conflict Ordering (`src/domain/constraints.ts`):** Verify a single pinned assignment on an unavailable day triggers `UNAVAILABLE_DAY` conflict (must run *before* `checkMaxOneShiftPerDayRule`'s `if (count <= 1) continue`), while unpinned assignments on unavailable days are cleared and re-scheduled (`AC-P2-012`).
2. **FM-05 Non-Negative Uncoverable Residual (`derivedMetrics.ts` / `schedulerDiagnostics.ts`):** Test scenarios where a day has demand on an inactive shift cell alongside pinned/active assignments on other hours to confirm `uncoverableBigInt` never goes negative (`AC-P2-007`).
3. **Ctrl+Z Undo Ghost-Assignment Prevention (`src/state/assignmentActions.ts`):** Assign staff on Sun → disable Sun on shift (cascade deletes assignment) → press Undo → verify assignment is NOT resurrected on the now-inactive day (`AC-P2-005`).
4. **Persistence Corruption Recovery (`src/persistence/storageSchema.ts`):** Test tampered `localStorage` payloads with `daysOfWeek: []`, out-of-range days (`7`, `-1`), duplicates (`[1, 1]`), or an assignment pointing to an inactive shift day → verify `CORRUPT_SCHEMA` / `recovery_locked` (`AC-P2-001`, `AC-P2-002`).
5. **Modal Escape-Key Layering & Keyboard UX (`ManageShiftsModal.tsx`):** When `ConfirmDialog` for cascade-disabling days is open, pressing `Escape` should close only the confirm dialog, not the parent modal.
6. **Stage 2 Rebalance Invariant (`schedulerStage2.ts`):** Stress-test multi-iteration rebalancing with mixed `unavailableDays` to ensure no swap ever moves a staff member onto their unavailable day (`AC-P2-011`, `AC-P2-013`).
